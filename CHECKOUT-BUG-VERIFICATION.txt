KRYVEN ERA — CHECKOUT BUG FIX VERIFICATION

Primary root cause found:
- checkout.html loaded the Cashfree SDK as a blocking <script> before app.js.
- If the external Cashfree SDK was slow/blocked, app.js never initialized, leaving the checkout page blank.

Fix applied:
- Removed the blocking Cashfree SDK <script> from checkout.html.
- Cashfree is now loaded lazily only when the customer presses the final online-payment button.
- Checkout UI can therefore render independently of Cashfree SDK/network availability.
- Cache-busting version updated on checkout assets.
